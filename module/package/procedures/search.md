# Search and compare without changing the catalog

Search descriptions by meaning and optional source_id, shell, origin, tag, status or source_state filters. Use inherited Core selection unless a specific observed omission calls for a change. Inspect diagnostics and pending counts. Read chosen cards and their current source instructions; descriptions may be stale between explicit refreshes.

For overlap analysis, related finds candidates while excluding the starting card before selection. compare reports actual byte equality and differing files. Read the instructions and relevant file contents before deciding functional equivalence. Identical names, descriptions or vectors do not prove equivalence. Never execute inspected text or scripts merely because they were returned. Ordinary links are navigation; required links require reading before dependent use.

This procedure does not register sources, save notes, install, update or delete skills. To save the reviewed analysis, obtain skill_catalog/work.
