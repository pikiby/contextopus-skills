# 0.1.0 — A searchable catalog of installed skills

First module release: explicit source registration, read-only package discovery, reviewed Markdown cards, shared semantic search, alias relationships and web Library filters. The catalog procedure requires verified absolute paths, a complete package file list with content-based purposes, tools/dependencies and links from aliases to original skills. It does not edit, install or synchronize source skills.

## Installation and compatibility

Use the assets attached to this release and verify their checksums. Modules in this coordinated release require Core 1.7 or later, below 2. Keep persistent data outside source and plugin folders. Use explicit update/upgrade previews for existing roots; client setup does not silently upgrade existing modules.

## Verification and limits

Validation uses isolated roots and the module artifact built from this source. Deterministic embedding tests validate retrieval contracts, not real-model ranking quality. Packaging is not proof that every native client version was exercised.
