# 0.3.0 — Core guide() routes

Skill Catalog declares its procedures as routes of the Core `guide()` router.
Procedures no longer repeat the common Core rules, and shipped skills are entry
points that obtain them. Source skills remain read-only.

## Update and compatibility

Requires Core >=1.9,<2. Update Core first, then use
`contextopus modules update skill_catalog --source /path/to/skill_catalog`.
Existing cards and source registrations are preserved.

[Changes since 0.2.0](https://github.com/pikiby/contextopus-skills/compare/v0.2.0...v0.3.0).
