# 0.2.0 — Complete skill package descriptions

Catalog saves now derive absolute skill paths and the complete file inventory from
the inspected source. The agent supplies a purpose for every file after reading it;
missing or stale inventories cannot silently produce incomplete cards.

Save schemas require `file_purposes`, declare wikilink formats and require evidence
and a target for aliases/forwarders. Procedures explain these steps explicitly.
Source skills remain read-only: this release does not rename, synchronize or
rewrite installed skills.

## Update and verification

Requires Core >=1.7,<2; the coordinated release uses Core 1.8.0. Use
`contextopus modules update skill_catalog --source /path/to/skill_catalog`
with the extracted release folder. Existing cards and source registrations remain.
Refresh the catalog procedure before saving: older callers must supply the new
`file_purposes` mapping from the current inspected inventory.

Local catalog tests, module schema comparisons and installed-artifact checks passed.
These do not establish native assistant behavior or new Windows/macOS acceptance.
See [installation and usage](../../README.md).
